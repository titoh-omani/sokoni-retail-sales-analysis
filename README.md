# sokoni-retail-sales-analysis
End-to-end analysis of 1,200 retail transactions across 5 Nairobi branches: data cleaning and analysis in Python (pandas, Seaborn) and an interactive Tableau dashboard
# Sokoni Retail Data Cleaning and Analysis

## Project Overview

This project focuses on cleaning, transforming, and analyzing retail transaction data for Sokoni Retail using Python. The goal is to improve data quality and generate useful business insights about sales, profits, product performance, payment methods, and customer satisfaction.

The project uses Pandas and NumPy to clean and prepare the dataset. Matplotlib is used to create visualizations that help explain business performance and identify patterns in retail transactions.

## Project Objectives

- Inspect the retail dataset and identify data quality issues.
- Handle missing values and duplicate transactions.
- Standardize column names, text values, and data types.
- Recalculate missing sales and profit values using verified formulas.
- Create additional columns for profit margins, weekdays, and quarters.
- Analyze sales and profit trends across months, branches, and product categories.
- Examine payment methods, customer satisfaction, and product return rates.
- Export the cleaned dataset for further analysis and visualization in Tableau.

## Tools and Technologies

- **Python:** Main programming language used for data analysis.
- **Pandas:** Data cleaning, transformation, grouping, and aggregation.
- **NumPy:** Numerical calculations and validation.
- **Matplotlib:** Creating charts and visualizing business insights.
- **Jupyter Notebook:** Interactive environment for executing and documenting the analysis.
- **Tableau:** The cleaned dataset is prepared for potential use in Tableau dashboards.

## Data Cleaning Process

The notebook follows a structured data cleaning workflow:

1. Load and inspect the original retail dataset.
2. Standardize column names and remove unnecessary spaces from text values.
3. Identify and remove duplicate transactions using transaction IDs.
4. Convert dates to datetime format and standardize the returned column.
5. Validate existing month information and create consistent month fields.
6. Recalculate missing total sales and profit values using quantity, unit price, and cost price.
7. Preserve missing customer satisfaction ratings rather than inventing values.
8. Check for impossible values and investigate potential outliers.
9. Create additional analytical columns, including profit margin percentage, weekday, and quarter.
10. Validate the cleaned dataset and export it to CSV format.

## Key Visualizations

The project generates seven visualizations:

1. **Monthly Sales and Profit Trend:** Tracks monthly sales and profit throughout 2024.
2. **Sales and Profit by Branch:** Compares financial performance across retail branches.
3. **Profit by Product Category:** Examines total profit and profit margins by category.
4. **Top 10 Products by Profit:** Identifies the products generating the highest profits.
5. **Payment Methods:** Shows the proportion of transactions made through different payment methods.
6. **Customer Satisfaction and Return Rate by Branch:** Compares average customer ratings and product return rates across branches.
7. **Sales Heatmap by Branch and Month:** Highlights differences in monthly sales performance across branches.
